1. EXECUTIVE SUMMARY
--------------------------------------------------------------------------------
When attempting to generate custom animated presentation videos from the 
Hyparlink Dashboard's "Make something" page (located at /create-video), the 
output video consistently ignores the custom user prompt (e.g., Absolute Batman, 
product launches, custom brands) and instead renders an old, generic corporate 
presentation ("Empowering Next-Gen Startups with Scalable Cloud Infrastructure", 
"+124% Revenue Growth", "Step 01 Data Input", and "ollasoftware-building.jpg").

This behavior is caused by two compounding factors:
1. The provided Ollima API key is permanently disabled/revoked on Ollima's 
   cloud servers (HTTP 401 Unauthorized: "API key was disabled at 2026-09-18").
2. When the backend cannot reach an active AI model, it silently drops back to 
   the built-in "Deterministic Fallback Engine". This fallback engine contains 
   static, hardcoded scenes from the initial prototype that never change 
   regardless of what prompt is entered.

In contrast, when Antigravity AI (Gemini 3.8) generates videos in the chat, it 
acts as an autonomous full-stack software engineer: it writes custom HTML/SVG 
code, designs bespoke GSAP timelines, compiles TypeScript, and directly invokes 
the HyperFrames rendering engine.

3. WHY THE DASHBOARD CREATES "SOMETHING THAT HAS BEEN THERE FOR A LONG TIME"
--------------------------------------------------------------------------------
When you type a prompt into the "Make something" text area on the dashboard, the 
following architectural chain takes place:

1. Frontend Submission:
   apps/app/src/app/[locale]/(dashboard)/create-video/page.tsx calls 
   Convex mutation `projects.create({ prompt, duration, ... })`.

2. Convex Job Dispatch:
   packages/backend/convex/jobs.ts schedules an async job `video.generate` and 
   calls the background server at `http://localhost:4000/jobs/run`.

3. AI Provider Selection:
   Inside ai-composition-generator/src/ai/provider.ts:
   - The server inspects `process.env.AI_PROVIDER` and `process.env.AI_API_KEY`.
   - Because no active API key is valid, the server logs:
     "AI Provider: deterministic | Model: default-model"
   - It routes the request to `callDeterministicEngine()`.

4. The Fallback Template Lock-in:
   In `ai-composition-generator/src/ai/composition-builder.ts`:
   The deterministic engine was built as an offline prototype fallback. For any 
   prompt that does not match hardcoded rules, it executes a fixed layout sequence:
   - Scene 1: cinematic-title -> "Scalable Cloud Infrastructure"
   - Scene 2: metrics-grid    -> "+124% Revenue Growth", "99.9% Uptime", "10x Velocity"
   - Scene 3: split-diagram   -> "Step 01 Data Input", "Step 02 AI Analysis", "Step 03 Synthesis"
   - Scene 4: closing-summary -> "Explore Next Steps"
   - Default Asset:           -> "ollasoftware-building.jpg"

Because the AI key is disabled, the dashboard CANNOT connect to an LLM. It is 
forced into this deterministic fallback every single time, giving the impression 
that it "only creates something that was there for a long time."

6. STEP-BY-STEP RESOLUTION PLAN
--------------------------------------------------------------------------------
To make the dashboard's "Make something" area generate live, customized videos 
just like Antigravity AI, follow these steps:

STEP 1: Generate an Active API Key
1. Go to https://app.ollima.com in your web browser.
2. Sign in to your account.
3. In the sidebar, navigate to "Setup" -> "API keys" (or #/orgs/<slug>/keys).
4. Click "Create new key" (or "Generate API Key").
5. Copy the newly generated key (starts with sk-t0-...).

STEP 2: Configure the Backend Environment
Add the active key and preferred model to `packages/backend/.env.local` or root `.env`:
```env
AI_PROVIDER=ollima
AI_MODEL=gemini-3-flash
OLLAMA_BASE_URL=https://api.ollima.com/v1
OLLAMA_API_KEY=<YOUR_NEW_ACTIVE_KEY>
```
Alternatively, if using a direct Google Gemini API key:
```env
AI_PROVIDER=gemini
AI_MODEL=gemini-1.5-pro
AI_API_KEY=<YOUR_GEMINI_KEY>
```

STEP 3: Add an Interactive AI Settings Modal to the Dashboard UI
We can add a user-friendly "AI Settings" dialog directly on `/create-video`:
- Allows you to paste your active API key without modifying server files.
- Lets you select your desired model (e.g. `gemini-3-flash`, `glm-5.3`, `deepseek-v4`).
- Includes a "Test Connection" button that validates the key instantly.

STEP 4: Upgrade the Local Fallback Engine
Even when offline, update `StoryboardPlanner` to dynamically parse topics, 
colors, and headlines so that the local engine never falls back to the old 
building/cloud template.
