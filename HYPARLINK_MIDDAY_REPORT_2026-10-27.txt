PART 1: ON-CANVAS TEXT EDITING & ELEMENT SELECTION FIXES
--------------------------------------------------------------------------------

1. Dynamic Bounding Box Alignment (Live Iframe Measurement):
   - Issue:
     The blue selection outline ("H1 : CULTURE & MARKETS") and inline text editing 
     box appeared displaced to the middle-right of the screen instead of directly 
     on top of the rendered text.
   - Root Cause:
     Overlay coordinates were using static percentages with "translate(-50%, -50%)" 
     centering, whereas left-aligned scenes in HyperFrames (e.g. Westminster, 
     Culture & Markets) sit at "padding: 0 140px" (~7.3% left margin) with 
     flex-end vertical alignment.
   - Resolution:
     - Passed "compositionIframeRef" into ElementsCanvasOverlay.jsx.
     - Implemented "getDynamicPlacement(el)" that queries the live composition 
       DOM ("#sc${sceneIndex} .title.m, .sub.sb, .pill.k") and reads its real-time 
       "getBoundingClientRect()".
     - Normalized coordinates to exact viewport percentages ("leftPercent", 
       "topPercent", "widthPercent", "heightPercent") with "transform: none", 
       ensuring the selection box and text editor snap directly over the text.

2. In-Place Text Editor (<textarea> & <input>):
   - Sized the inline editing container to 100% width and 100% height directly 
     over the element, styled with matching font-family, font-size, line-height, 
     and text alignment.
   - Set non-editing text to transparent so the crisp composition text underneath 
     shows through with zero visual duplicate or ghost text.
   - Added two-way live synchronization: typing in the textarea updates 
     the composition iframe DOM ("targetEl.innerHTML / textContent") in real time.

3. Element Deletion & Management:
   - Added inline "✕ Del" and "✎ Edit" action triggers on the element tag badge.
   - Added support for keyboard Delete and Backspace shortcuts to delete 
     selected elements directly.
