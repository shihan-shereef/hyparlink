4. TYPOGRAPHY ENGINE FIX: SOLVING THE IDENTICAL FONT ISSUE
--------------------------------------------------------------------------------
Problem Reported by User:
  "in this vido also the font is same as the every other vido there is no difarans
   in it and it is not chagngeng at all so make it work prparly"

Forensic Investigation & Root-Cause Analysis:
  1. Font Fallback Hijacking:
     Every generated scene HTML and master `index.html` contained an injected CSS
     block generated by `design-validator.ts`:
     `@font-face { font-family: 'Space Grotesk'; src: local('Space Grotesk'), local('Inter'), sans-serif; }`
  2. Chromium Headless Local Resolution Failure:
     In headless Chromium (used by HyperFrames CLI and Puppeteer), `local('...')`
     fails unless the user has manually installed the font onto their macOS/Linux
     system font book.
  3. Blocking Google Fonts:
     Because the browser encountered the invalid `@font-face` declaration with
     `local()` fallback, it immediately aborted web font retrieval and defaulted
     to the browser's lowest-common-denominator system font: Arial / Helvetica.
     Consequently, every single video looked visually identical in typography.

Code Implementation & Fix:
  1. `ai-composition-generator/src/ai/storyboard-planner.ts`:
     Implemented dynamic `selectFonts(style, lowerPrompt, topic)`:
     - Superhero / Cinematic Comic: `Bebas Neue` (Display) + `Montserrat` (Body)
     - Tech / Cyberpunk / AI: `Orbitron` (Display) + `Space Grotesk` (Body)
     - Luxury / Editorial: `Playfair Display` (Display) + `Cinzel` (Body)
     - Kinetic / Modern Bold: `Syne` (Display) + `Outfit` (Body)
     - Clean SaaS / Corporate: `Plus Jakarta Sans` (Display) + `Inter` (Body)
  2. `ai-composition-generator/src/ai/composition-builder.ts`:
     - Injected full Google Fonts preconnect and multi-family stylesheet bundle
       into `<head>` of both `index.html` and every `scene_*.html`.
     - Removed blocking `@font-face { src: local(...) }` declarations.
     - Replaced hardcoded font strings in comic title overlays and dossiers
       with dynamic `brief.displayFont`.
  3. `ai-composition-generator/src/ai/composition-synthesizer.ts`:
     - Guaranteed Google Fonts stylesheet link is present in all synthesized scenes.
  4. `ai-composition-generator/src/hyperframes/design-validator.ts`:
     - Removed the broken local `@font-face` injector.
     - Replaced with validation that checks for valid Google Fonts stylesheet links.
  5. UI Selector in `/create-video`:
     - Added a dedicated "Typography & Fonts" selector dropdown so users can either
       let the AI auto-detect based on genre, or explicitly select their desired
       font pairing (Bebas Neue, Orbitron, Playfair Display, Syne, Plus Jakarta).

5. NATIVE HEYGEN AVATAR INTEGRATION (DIRECT AVATAR ID & VOICE ID)
--------------------------------------------------------------------------------
Problem & User Requirement:
  "i need the heygen agen to be intagrat in side this dashbord insted of coping
   the feachesa and past it it has to work like whien create an accund and after
   flling the foms i can copy my avathar id and voice id from the heygen and use it
   to create a vedo based on that avathar whcih i crated in it so make it like that"

Architecture & Solution:
HeyGen provides an API v2 (`POST https://api.heygen.com/v2/video/generate`) which
accepts an `avatar_id` string and a `voice_id` string. When a user creates an
Instant Avatar (or Studio Avatar) on HeyGen, HeyGen assigns it a unique Avatar ID
(e.g., `Angela-in-office-20240820` or a UUID). 

Instead of manual feature re-creation, the dashboard now natively ingests and routes
the user's custom Avatar ID and Voice ID!

Implementation Details:
  1. Backend HeyGen Service (`backend-echo/heygen/heygen-service.mjs`):
     - Added live catalog discovery functions `getAvatars(apiKey)` and `getVoices(apiKey)`
       to query `https://api.heygen.com/v2/avatars` and `voices` with the user's key.
     - Updated `generateCloudVideo`:
       Takes `{ avatarId, voiceId, script, speed, pitch, emotion, background, resolution }`
       and transmits it directly to HeyGen's Cloud Video Generation endpoint.
     - Updated `generateLocalStudioVideo`:
       Gracefully handles custom Avatar IDs and Voice IDs in local studio preview mode
       without falling back to hardcoded default names.
  2. Backend Echo Server (`backend-echo/server.mjs`):
     - Updated `/api/heygen/avatars` and `/api/heygen/voices` to accept user API keys
       from query parameters and headers, enabling dynamic account catalog fetching.
  3. HeyGen Studio UI (`apps/app/src/app/[locale]/(dashboard)/heygen/page.tsx`):
     - Added a Mode Toggle in Step 2:
       * Button A: "Curated Presenters" (Sarah, Marcus, Elena, Alex)
       * Button B: "My Custom HeyGen Avatar (Direct ID)" with Sparkles badge.
     - Built Custom Avatar Input Form:
       * "HeyGen Avatar ID" (Required): e.g. `Angela-in-office-20240820` or UUID.
       * "HeyGen Voice ID" (Optional): Cloned voice ID from HeyGen account.
       * Step-by-step guidance card showing exactly how to log into app.heygen.com,
         navigate to Avatars, and copy the ID.
       * Real-time validation indicator confirming ready status.
       * Automatic persistence to browser `localStorage` (`heygen_custom_avatar_id`
         and `heygen_custom_voice_id`).
  4. Create Video Studio Launcher (`apps/app/src/app/[locale]/(dashboard)/create-video/page.tsx`):
     - Added a dedicated "HeyGen Avatar Presenter Studio" banner.
     - Displays live status of the configured custom Avatar ID.
     - Features direct link and quick-launch button to `/heygen`.

8. USER GUIDE: HOW TO USE CUSTOM HEYGEN AVATAR & NEW FONTS
--------------------------------------------------------------------------------
How to use your custom HeyGen Avatar in the Dashboard:
  1. Open the dashboard at:
     https://berlin-rental-listed-committee.trycloudflare.com/heygen
  2. In Step 1:
     Paste your HeyGen API Key (from app.heygen.com -> Settings -> API) and click Connect.
  3. In Step 2 (Select Your AI Avatar):
     Click the "My Custom HeyGen Avatar (Direct ID)" tab.
  4. Paste your HeyGen Avatar ID:
     - Open app.heygen.com, go to "Avatars", and open your custom avatar.
     - Copy the Avatar ID (e.g. `Angela-in-office-20240820` or your avatar UUID)
       and paste it into the "HeyGen Avatar ID" box.
  5. Paste your Voice ID (Optional):
     - If you cloned your voice in HeyGen, paste its Voice ID.
  6. Enter your script and click "Generate Studio Video"!
     - The video will render featuring your exact custom avatar!

How to choose different fonts in Create Video:
  1. Open:
     https://berlin-rental-listed-committee.trycloudflare.com/create-video
  2. Under the prompt box in the settings row, locate "Typography & Fonts".
  3. Choose your desired style:
     - "Auto-Adaptive (AI Genre)": Automatically picks fonts matching your prompt.
     - "Heroic Comic": Bold uppercase Bebas Neue + Montserrat.
     - "Cyberpunk Tech": Glowing Orbitron + Space Grotesk.
     - "Luxury Editorial": Elegant Playfair Display + Cinzel.
     - "Modern Kinetic": Ultra-punchy Syne + Outfit.
     - "Clean SaaS": Plus Jakarta Sans + Inter.
  4. Click Generate — fonts are fetched directly via Google Fonts CDN in real-time!
