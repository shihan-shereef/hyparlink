6. ROOT CAUSE & PERMANENT FIX: THE DOWNLOAD FILENAME BUG
--------------------------------------------------------------------------------
Issue Reported:
  Every download from the dashboard produced "quarterly-revenue-analytics-1080p.mp4",
  regardless of what prompt was entered or what video was created.

Investigation & Root Cause Analysis:
  1. In create-video/page.tsx, selecting an inspiration card preset wrote
     "Quarterly Revenue & Analytics" into the React name state. Editing the prompt
     did not clear this state, causing the preset title to persist in the database.
  2. In packages/backend/convex/jobs.ts, when the video generation job completed,
     the project record in Convex was never updated with the AI storyboard title.
  3. In projects/[id]/page.tsx, the handleDownload function directly read project.name
     without cross-checking prompt keywords, creating "quarterly-revenue-analytics-1080p.mp4".
  4. In backend-echo/server.mjs, the streamFile streaming endpoint hardcoded
     Content-Disposition: attachment; filename="video.mp4" and ignored custom filename
     query parameters or project directory metadata.

Fixes Implemented:
  1. create-video/page.tsx:
     - Added prompt change listener to automatically clear/update preset titles.
     - Added smart deriveProjectName logic in handleSubmit prioritizing prompt topics.
  2. packages/backend/convex/projects.ts:
     - Added deriveProjectName on both create and createInternal mutations.
     - Added renameInternal mutation and updated existing database records.
  3. packages/backend/convex/jobs.ts:
     - Synchronized proj.name with result.title or result.storyboard.title upon job completion.
  4. backend-echo/server.mjs:
     - Enhanced streamFile to honor ?filename= query parameters for Content-Disposition.
     - Added fallback to project-map.json / meta.json so direct requests without query
       parameters resolve to the project title instead of generic filenames.
  5. projects/[id]/page.tsx:
     - Implemented unified computeDownloadFilename helper for both client-side Blob
       download and native Direct Link anchor.
