## 1. Executive Summary

In Phase 5, we built and verified the standalone **AI Composition Generator Prototype** (`ai-composition-generator/`) that converts a natural-language video prompt into a valid HyperFrames project and renders it into a production MP4 video.

### Core Constraints Respected:
- **Zero Convex Modifications**: The existing Convex dashboard, schema, and functions were untouched.
- **Project Isolation**: No existing HyperFrames projects were modified or overwritten.
- **HyperFrames Version**: Executed strictly with `npx --yes hyperframes@0.8.139`.
- **Validation Before Render**: Every project is strictly checked via `npx hyperframes@0.8.139 check --json`. Rendering is only initiated if validation passes. If validation fails, an automatic 3-attempt AI correction loop triggers. If errors persist, rendering is aborted.

```
USER PROMPT
    ↓
AI MODEL (OpenAI / Anthropic / HuggingFace / Gemini / Deterministic)
    ↓
HTML + CSS + JavaScript / GSAP
    ↓
Isolated Project (generated-projects/job-<id>/)
    ↓
HyperFrames Check (0 lint/runtime errors)
    ↓
HyperFrames Render (Headless Chrome + Metal Hardware GPU + FFmpeg)
    ↓
OUTPUT MP4 (1920x1080 @ 30fps)
```

## 3. Architecture Explanation

### A. Modular Composition Structure
HyperFrames 0.8.139 enforces a clean composition contract to avoid `nested_structure_needs_subcomposition` warnings:
- **`index.html` (Master Host)**:
  Declares the root canvas:
  ```html
  <div id="root" data-composition-id="main" data-start="0" data-duration="5" data-width="1920" data-height="1080">
    <div id="scene-01-host" class="scene-host clip" data-composition-id="scene-01" data-composition-src="compositions/scene_01.html" data-start="0" data-duration="5"></div>
  </div>
  <script>
    window.__timelines = window.__timelines || {};
    const tl = gsap.timeline({ paused: true });
    window.__timelines["main"] = tl;
    tl.seek(0);
  </script>
  ```
- **`compositions/scene_01.html` (Scene Implementation)**:
  Contains visual DOM elements, typography, CSS, and GSAP timeline:
  ```html
  <div id="scene-01-root" data-composition-id="scene-01" data-start="0" data-duration="5" data-width="1920" data-height="1080">
    <!-- Visual DOM -->
  </div>
  <script>
    window.__timelines = window.__timelines || {};
    const tl = gsap.timeline({ paused: true });
    // Deterministic animations
    window.__timelines["scene-01"] = tl;
    tl.seek(0);
  </script>
  ```

### B. Validation & 3-Attempt Auto-Correction Loop
1. When project files are generated, `Validator.validate(projectDir)` runs `npx --yes hyperframes@0.8.139 check --json`.
2. If `StaticGuard` or lint rules report errors (e.g. missing timeline registration, invalid duration, or CSS transform conflict), the pipeline triggers `AIGenerator.correctProject()` with the error log and previous files.
3. The project is rewritten and re-checked up to **3 consecutive attempts**.
4. If validation passes, rendering proceeds. If all 3 attempts fail, the pipeline halts with `renderStatus: SKIPPED` and outputs the exact validation errors.

### C. Headless GPU Render Engine
- Rendering runs `npx --yes hyperframes@0.8.139 render --resolution 1080p --format mp4 -o <output.mp4>`.
- The renderer automatically discovers and injects the bundled Apple Silicon FFmpeg binary (`/Applications/HyperFrames.app/Contents/Resources/app.asar.unpacked/vendor/ffmpeg/darwin-arm64`) into `PATH`.
- HyperFrames leverages Headless Chrome with ANGLE Metal GPU acceleration (`Apple M1`) for fast frame capture and H.264 streaming encode.

## 4. AI Provider & Configuration

The AI provider is configurable through standard environment variables:

```bash
# Configurable provider: 'openai' | 'anthropic' | 'huggingface' | 'gemini' | 'deterministic'
AI_PROVIDER=openai

# Model name:
AI_MODEL=gpt-4o

# Secret key (kept server-side only):
AI_API_KEY=sk-...
```

### Safety & Error Handling:
- If `AI_PROVIDER` is set to an external provider without `AI_API_KEY`, a descriptive error is raised immediately.
- If no provider or keys are specified, the system defaults to the **`deterministic` engine**, which synthesizes 100% compliant HyperFrames compositions matching prompt parameters (duration, resolution, theme, animations) for zero-cost offline testing and continuous integration.

## 8. Known Limitations & Next Steps

1. **Asset Generation**:
   - Currently, animations use procedural SVG, CSS grid overlays, and GSAP motion. For custom PNG/video assets, external image assets must be placed in `assets/` or downloaded during generation.
2. **Audio Track Support**:
   - Audio elements must have explicit `id` attributes and deterministic duration. Audio synthesis (TTS/music) will be hooked in subsequent phases.
3. **Transition to Convex Integration (Phase 6)**:
   - Now that the standalone prototype proves `Prompt ➔ AI ➔ Validate ➔ Auto-Fix ➔ Render ➔ MP4`, this core pipeline can be integrated into the Convex dashboard job queue without risking regressions.
