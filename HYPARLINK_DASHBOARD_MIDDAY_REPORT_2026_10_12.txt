2. CRITICAL BUGS & BLOCKERS RESOLVED
--------------------------------------------------------------------------------

A. CONVEX `projects:create` ARGUMENT VALIDATION ERROR
   - Symptom: Server Error ArgumentValidationError: Object contains extra field
     `model` that is not in the validator when submitting `/create-video`.
   - Root Cause: Frontend added the AI model selector to the mutation payload, but
     `packages/backend/convex/projects.ts` did not declare `model` in its schema validator.
   - Resolution: Added `model: v.optional(v.string())` to `projects:create` args and
     persisted the selected model to the project document for pipeline propagation.
   - File Modified: `packages/backend/convex/projects.ts`

B. ASSET PATH TRAVERSAL IN STUDIO PREVIEW (`invalid_parent_traversal_in_asset_path`)
   - Symptom: HyperFrames Studio and editor preview threw validation error:
     "Found 1 asset path(s) traversing above the project root with '../' (../assets/).
     Studio preview and live consumers resolve against project root and 404."
   - Root Cause: HyperFrames compositions are served with the project root as their
     base URL. Sub-compositions using `../assets/` fail Studio live preview.
   - Resolution:
     1. Updated `CompositionSynthesizer` to strictly emit root-relative `assets/${name}`.
     2. Built auto-repair rule into `DesignValidator` normalizing `../assets/` -> `assets/`.
     3. Scanned and repaired all existing project files across the workspace.
     4. Integrated `DesignValidator.inspect(projectDir)` directly into `server.mjs`
        prior to starting or reusing any Studio session.
   - Files Modified:
     * `ai-composition-generator/src/ai/composition-synthesizer.ts`
     * `ai-composition-generator/src/hyperframes/design-validator.ts`
     * `backend-echo/server.mjs`

C. PROJECT DELETION LOGIC
   - Verified project deletion mutations in Convex backend so users can cleanly
     remove completed or test projects from their workspace without residual orphan locks.

4. THE COMPLETE PIPELINE RE-ARCHITECTURE
--------------------------------------------------------------------------------
Why Antigravity produced superior videos compared to the old dashboard pipeline:
  - Old Pipeline: Asked LLM for basic titles, then poured text into 8 rigid HTML cards
    with mandatory 80px `.bg-grid` CSS backgrounds and 460px container bounds.
  - New Pipeline: The LLM drives a full Creative Brief, which is dynamically
    synthesized into custom HTML5, inline SVG geometry, and GSAP motion code.

Target Pipeline Workflow:
  [1] USER PROMPT & AUTHORITATIVE DURATION (e.g. 30s @ 30fps = 900 frames)
        │
        ▼
  [2] OLLIMA LLM REASONING & UNDERSTANDING (deepseek-v4-flash)
        │
        ▼
  [3] CREATIVE BRIEF GENERATION (Category, palette, typography, narrative arc)
        │
        ▼
  [4] WORKSPACE ASSET ANALYSIS (Dimensions, hero role, safe text zone, scrim)
        │
        ▼
  [5] SCENE-BY-SCENE TIMELINE PLANNING (Mathematical frame reconciliation to 900f)
        │
        ▼
  [6] DYNAMIC COMPOSITION SYNTHESIS (HTML/CSS/inline SVG charts/counters/GSAP)
        │
        ▼
  [7] HYPERFRAMES PROJECT GENERATION (compositions/, assets/, hyperframes.json)
        │
        ▼
  [8] DESIGN VALIDATOR & AUTO-REPAIR (Font fallbacks, relative path normalization)
        │
        ▼
  [9] HYPERFRAMES GPU VIDEO RENDERING (npx hyperframes@0.8.139 render)
        │
        ▼
 [10] HEADLESS FFPROBE & FRAME QUALITY QA (Duration verification, freeze detection)
        │
        ▼
 [11] MEDIA STORAGE & REAL-TIME DASHBOARD PLAYBACK
