1. EXECUTIVE OVERVIEW
--------------------------------------------------------------------------------
The HyperFrames video-generation dashboard has been upgraded into a fully autonomous 
5-stage video creation agent. The integrated LLM (Ollama gemma4) reasons over the user's
prompt, planned timing, visual motion, self-audit, and rendering pipeline without relying
on hardcoded generic corporate templates.

THE FIVE AUTONOMOUS AGENT STAGES:
  [STAGE 1] Writes a composition: Creates creative brief, visual layout, and HyperFrames compositions.
  [STAGE 2] Times the clips: Plans frame-accurate timelines conforming to user durations.
  [STAGE 3] Animates the elements: Generates deterministic GSAP timelines and SVG morphs.
  [STAGE 4] Checks its own work: Autonomous self-auditor + bounded auto-repair loop (max 3 retries).
  [STAGE 5] Renders the video: Headless HyperFrames render + FFprobe media verification.

All operations strictly obey the environment restrictions:
- ZERO browser automation, Puppeteer, Playwright, or Selenium.
- Completely headless CLI execution, Node.js scripts, FFmpeg, and FFprobe.
- Convex database jobs and Next.js dashboard UI state remain fully preserved.


2. ARCHITECTURE OF THE 5 AGENT STAGES
--------------------------------------------------------------------------------

STAGE 1: WRITES A COMPOSITION
- Location: ai-composition-generator/src/ai/generator.ts & creative-brief.ts
- Operation:
  1. Ingests user prompt, requested duration, aspect ratio, resolution, and selected assets.
  2. Generates a structured Creative Brief via LLM (route, spec, beats, copy, techniques, negatives).
  3. Classifies video into tailored aesthetic categories (cinematic, nature growth, data viz, network architecture, abstract geometric, architectural showcase, or asset ad).
  4. Synthesizes bespoke HTML/CSS layouts, typography hierarchy, and SVG elements reflecting the prompt.

STAGE 2: TIMES THE CLIPS
- Location: ai-composition-generator/src/ai/scene-planner.ts
- Operation:
  1. Computes mathematical pacing dividing user duration into logical narrative beats.
  2. Calculates non-zero, strictly positive scene start, duration, end, startFrame, and endFrame.
  3. Propagates duration through metadata, root index.html (data-duration="XX.XX"), and scene files.
  4. Guarantees no negative durations, no unintentional gaps, and exact sum of scene durations.

STAGE 3: ANIMATES THE ELEMENTS
- Location: ai-composition-generator/src/ai/composition-synthesizer.ts
- Operation:
  1. Emits deterministic GSAP timelines (gsap.timeline({ paused: true })) indexed in window.__timelines.
  2. Uses GPU-accelerated CSS transforms (scale, opacity, transform) avoiding layout reflow (left, top).
  3. Tailors motion to concept: botanical SVG growth for trees, dynamic bar scaling for charts, glowing packet pulses for network explainers, and camera zooms for cinematic teasers.
  4. Ensures animations seek deterministically at exact timestamps for headless frame capture.

STAGE 4: CHECKS ITS OWN WORK (AUTONOMOUS AUDIT & SELF-REPAIR)
- Location: ai-composition-generator/src/ai/composition-auditor.ts
- Operation:
  1. Evaluates 5 pillars: Prompt Compliance, Composition Structure, Timing Rigor, Visual Quality, and Audio Contract.
  2. Runs programmatic checks on files, metadata, HTML tags (hyper-scene or data-composition-id), and GSAP properties.
  3. Evaluates prompt compliance via LLM semantic scoring (target threshold >= 75/100).
  4. Auto-Repair Loop: If audit fails or lint issues occur, AIGenerator.correctProject() submits the precise error diagnostics back to the LLM to patch affected files (up to 3 bounded correction attempts).

STAGE 5: RENDERS THE VIDEO & FFPROBE VERIFICATION
- Location: ai-composition-generator/src/hyperframes/renderer.ts & pipeline/generate-video.ts
- Operation:
  1. Invokes headless `hyperframes render` CLI in the isolated project directory.
  2. Captures real-time CLI stderr/stdout progress.
  3. Automatically runs FFprobe on the rendered MP4 verifying file readability, resolution (e.g. 1920x1080), framerate (30fps), duration (within frame tolerance), and audio stream presence/absence.
  4. Stores final media via storage abstraction (local/R2/S3) and updates Convex job record.
