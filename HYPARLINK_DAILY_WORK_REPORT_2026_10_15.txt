B. MULTI-PROVIDER DISCOVERY SYSTEM
Files: `ai-composition-generator/src/images/wikimedia-provider.ts`
       `ai-composition-generator/src/images/pexels-provider.ts`
       `ai-composition-generator/src/images/unsplash-provider.ts`

- Wikimedia Commons Provider:
  * Interfaces with the MediaWiki Action API (`api.php`) with compliant User-Agent headers.
  * Automated Query Simplification: Detects zero-result responses on complex multi-word
    queries and automatically simplifies them by stripping stop-words and retrying with

  * License Extractor: Parses machine-readable metadata (`extmetadata`) for CC BY,
    CC BY-SA, and Public Domain designations.
- Workspace Provider:
  * Scans local project and upload directories (`public/uploads`, `assets/`, etc.).
  * Enforces #1 Priority: User files are always evaluated and preferred over external web images.
- Stock Providers (Pexels & Unsplash):
  * REST API integrations with resolution filtering (minimum 1920x1080) and attribution tracking.

--------------------------------------------------------------------------------
C. 10-FACTOR MULTI-ATTRIBUTE IMAGE RANKER
File: `ai-composition-generator/src/images/image-ranker.ts`
--------------------------------------------------------------------------------
Every discovered candidate is scored across 10 weighted dimensions (0-100 score):
  1. Subject Relevance (20%): Keyword match against scene requirements.
  2. Scene Context Match (12%): Semantic alignment with narration.
  3. Visual Quality & Crispness (12%): Bit depth, compression quality, and sharpness.
  4. Resolution Headroom (12%): Preference for 1080p, 2K, and 4K masters.
  5. Aspect Ratio Alignment (10%): Match with target 16:9, 9:16, or 1:1 canvas.
  6. Compositional Negative Space (8%): Safe zones for headline text overlay.
  7. Motion / Animation Fit (8%): Ample border margins for Ken Burns scaling.
  8. Historical Authenticity (8%): Era-accurate matching for documentary prompts.
  9. Licensing Compliance (5%): Hard requirement for commercial/open CC licenses.
  10. Source Domain Reliability (5%): Verified CDN and repository health.

--------------------------------------------------------------------------------
D. SSRF-SAFE DOWNLOADER WITH MAGIC-BYTE FORMAT VERIFICATION
File: `ai-composition-generator/src/images/image-downloader.ts`
--------------------------------------------------------------------------------
- SSRF Guardrails: Validates target URLs, blocking private IP ranges (`127.0.0.1`, `10.0.0.0/8`,
  `192.168.0.0/16`, AWS/cloud metadata endpoints).
- Binary Magic-Byte Inspection: Inspects the initial 16 bytes of every downloaded buffer:
  * JPEG: `FF D8 FF`
  * PNG: `89 50 4E 47 0D 0A 1A 0A`
  * WebP: `52 49 46 46` ... `57 45 42 50`
  * Rejects HTML error pages masquerading with HTTP 200 headers or corrupted media.
- File-Size Safeguards: Enforces maximum limits (35 MB) and minimum thresholds (15 KB)
  to prevent denial-of-service and corrupt placeholder rendering.

--------------------------------------------------------------------------------
E. HYPERFRAMES COMPOSITION & GSAP CAMERA MOTION INTEGRATION
Files: `ai-composition-generator/src/ai/composition-synthesizer.ts`
       `ai-composition-generator/src/pipeline/generate-video.ts`
--------------------------------------------------------------------------------
- Asset Staging: Copies verified image assets into `projectDir/assets/` with deterministic names.
- Multi-Plane HTML Injection: Renders images with `object-fit: cover`, dark radial vignette
  overlays (`linear-gradient(to bottom, rgba(15,23,42,0.4), rgba(15,23,42,0.85))`), and
  layered glassmorphic text containers.
- GSAP Camera Movement:
  * `ken_burns_zoom_in`: Smooth `scale: 1.00` to `1.10` over scene duration.
  * `slow_pan_horizontal`: Subtle horizontal translation `x: "-3%"` with soft ease.
  * `parallax_depth`: Foreground text moves faster than background image plane.
