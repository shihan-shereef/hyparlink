A. UNIVERSAL VIDEO EDITING & CANVAS INTERACTION RESOLUTION
--------------------------------------------------------------------------------
Problem Analysis:
Why was the London reference video editable while other generated videos
(e.g., Nike shoe ad `jracm`, `pekt2`, `csp4i`, etc.) suffered from broken text
movement, unselectable images, and resize failures?
1. Responsive Flex Layouts: London used fixed `html, body { width: 1920px; height: 1080px; }`
   and absolute-positioned `.content` with pixel typography. Other videos used
   `width: 100%; height: 100%`, flexbox `.ad-scene`, and `font-size: clamp(...)`.
   Setting `position: absolute` on an element removed it from flow, collapsing the
   parent container height and causing flexbox to vertically re-center siblings,
   making dragged text violently jump or drift away from the cursor.
2. Background Hijacking Image Clicks: `.scene-background` gradient divs were matched
   ahead of real `<img>` tags in DOM queries, causing clicks on images to select the
   full-screen background instead.
3. CSS Constraints Blocking Resize: Rules like `max-height: 48vh`, `width: min(78vw, 760px)`,
   and `@keyframes shoe-float` overrode canvas transform updates.
4. Auto-Save String Duplication: Rapid pointer moves repeatedly appended inline
   `position: absolute; left: X%; top: Y%` into HTML files, producing dozens of
   duplicate semicolons and corrupted tags.

Engineering Solutions Implemented:
1. Image Selection De-Hijacking:
   - In `ElementsCanvasOverlay.jsx` and `interactive-canvas.tsx`, excluded
     `.scene-background`, `.scene-overlay`, `.grid-overlay`, and `.film-grain`.
   - Added direct matching for `<img>`, `.product-image`, `.feature-image`, and visual
     SVGs by source attribute, image classes, and scene index context.
2. Layout Spacer Insertion (`.hf-layout-spacer`):
   - In `App.jsx`, when an element transitions to `position: absolute` during drag,
     an invisible spacer matching the element's exact computed width, height, and
     margins is automatically inserted into its previous DOM position.
   - Result: Taking elements out of document flow never collapses the parent container,
     completely eliminating sibling jumps and cursor drift.
3. Image & Text Resizing Overrides:
   - When an image is moved or resized, `style.maxWidth = "none"`, `style.maxHeight = "none"`,
     and `style.animation = "none"` are applied so CSS animations or viewport units
     do not constrain manual sizing.
   - For text resizing, `style.fontSize` is set in pixels, `style.lineHeight = "1.1"` is
     enforced, and `style.fontSize = "inherit"` is propagated to split spans (`.ch`, `.w`, `.row`).
4. Bounding Box & Dimension Normalization:
   - In `ElementsCanvasOverlay.jsx`, replaced hardcoded resolution divisors with dynamic
     iframe document bounds (`(left / docW) * 100` and `(top / docH) * 100`).
   - Carried measured `widthPx` and `heightPx` in `setResizing` and `setDragging`
     `initPlacement`, and protected style setters against `NaN`.
5. Map-Based Auto-Save Deduplication:
   - Replaced naive string appending with a property map that guarantees each CSS
     property occurs exactly once.
   - Automatically filters out container wrappers (`<section>`, `<body>`, `<html>`,
     `#root`, `#scenes`, `#composition`, `.scene-background`).
