## 4. Video Thumbnail Architecture

- **Extraction Time**: Approximately `00:01` (1 second mark). If the video is shorter than 1 second, it falls back to `00:00:00.1` (the first available frame).
- **Format**: Modern `WebP` (`image/webp`) encoded via FFmpeg `libwebp`.
- **Dimensions**: Aspect-ratio preserving (`1280x720` for 16:9, `720x1280` for 9:16, `1080x1080` for 1:1).
- **Storage Key**: `workspaces/{workspaceId}/projects/{projectId}/renders/{jobId}/thumbnail.webp`.
- **Non-Fatal Resilience**: Thumbnail generation runs inside a `try/catch` block. If thumbnail extraction fails, the video render remains `completed` and `thumbnailStatus` is set to `"failed"`, avoiding any interruption of video delivery.

---

## 5. Multi-Resolution Architecture

- **Master Render**: HyperFrames 0.8.139 produces the 1080p master MP4 (`1920x1080`).
- **Transcoding Profiles**:
  - `1080p`: Master file preserved as the high-fidelity output.
  - `720p`: Transcoded to `1280x720` via FFmpeg `libx264` (`crf=22`, `preset=fast`, `-c:a copy`).
  - `480p`: Transcoded to `852x480` via FFmpeg `libx264` with filter `scale=854:480:force_original_aspect_ratio=decrease,scale=trunc(iw/2)*2:trunc(ih/2)*2` (`crf=24`, `preset=fast`, `-c:a copy`).
- **Configurability**: Controlled by `RENDER_PROFILES` environment variable (defaulting to `1080p,720p,480p` or overridable per job request in `input.profiles`).
- **Storage Keys**:
  - `workspaces/{workspaceId}/projects/{projectId}/renders/{jobId}/video.mp4` (1080p master)
  - `workspaces/{workspaceId}/projects/{projectId}/renders/{jobId}/720p/video.mp4`
  - `workspaces/{workspaceId}/projects/{projectId}/renders/{jobId}/480p/video.mp4`
- **Partial Failure Handling**: If an optional lower resolution fails to encode, the project remains `completed` and the failed resolution is recorded with `status: "failed"` while other resolutions remain accessible.

---

## 6. Optional HLS Adaptive Streaming Architecture

- **Control Flag**: Controlled by `HLS_ENABLED=true` (defaults to `false`).
- **Structure**:
  - `master.m3u8`: Master multi-bitrate playlist referencing sub-streams.
  - `index.m3u8`: Stream playlist.
  - `segment_%03d.ts`: 4-second MPEG-TS segments.
- **Storage Key**: `workspaces/{workspaceId}/projects/{projectId}/renders/{jobId}/hls/`.
- **Player Integration**: The dashboard video player plays MP4 by default, with automatic fallback support.

## 7. Workspace Asset Library Architecture

- **Navigation**: Dedicated "Assets" route at `/(dashboard)/assets`.
- **Supported File Types**:
  - Images: `image/png`, `image/jpeg`, `image/webp`, `image/svg+xml`.
  - Videos: `video/mp4`, `video/webm`.
  - Audio: `audio/mpeg`, `audio/wav`, `audio/aac`, `audio/mp4`.
  - Fonts: `font/woff`, `font/woff2`, `font/ttf`, `font/otf`.
- **Size Limits**:
  - Images: 20 MB max.
  - Videos: 500 MB max.
  - Audio: 100 MB max.
  - Fonts: 20 MB max.
- **Preview Engine**:
  - Images: Live responsive thumbnail rendering.
  - SVGs: Safe vector graphic previewing.
  - Video: HTML5 video tag preview.
  - Audio: Native HTML5 audio player controls.

## 9. AI Asset Integration

- **Manifest Contract**: When a user selects workspace assets on the Create Video page, an authorized manifest is passed to the AI pipeline:
  ```json
  [
    {
      "id": "asset_1791460522857_fbbc9c",
      "name": "acme-logo.svg",
      "type": "image",
      "mimeType": "image/svg+xml",
      "storageKey": "workspaces/ws-a/assets/.../acme-logo.svg",
      "url": "http://localhost:4000/storage/workspaces/ws-a/assets/..."
    }
  ]
  ```
- **Local Composition Isolation**: The backend pipeline downloads authorized assets into `projectDir/assets/` before invoking HyperFrames.
- **Composition Generation**: The AI engine embeds the asset reference `<img src="assets/acme-logo.svg" class="brand-logo" />` into `compositions/scene_01.html` along with GSAP animation triggers.

---

## 10. Security & Workspace Isolation Implementation

1. **Workspace Boundary**: Assets are partitioned by `workspaceId`. Workspace A cannot view, stream, or delete Workspace B assets.
2. **Server-Side Validation**: Browser-supplied `assetIds` are validated against `workspaceId` prior to job submission.
3. **MIME & Executable Blocking**: Unsupported file types (e.g., `.exe`, `.sh`, `.bat`) are rejected with `HTTP 400 Bad Request`.
4. **Path Traversal Protection**: Storage key requests are normalized and verified within the workspace root.
5. **No Credential Leakage**: The AI generation prompt only receives public/signed HTTP URLs, never raw cloud credentials or access tokens.

---

## 11. Cleanup Implementation

- **Temporary Render Files**:
  - Temporary transcoding files (`/tmp/720p-*.mp4`, `/tmp/480p-*.mp4`) are unlinked immediately after upload to storage.
  - Temporary HLS directories (`/tmp/hls-*`) are removed after playlist sync.
  - Local asset copies inside `ai-composition-generator/generated-projects/job-*/assets/` are isolated per job and cleaned up without touching source workspace assets.
- **Storage Deletion**: Deleting an asset removes its underlying cloud storage object.

## 20. Known Limitations

1. **Local FFmpeg Execution**: In the current local environment, transcoding is performed sequentially after the master render finishes. In high-traffic production environments, lower resolution encoding can be offloaded to worker queues (e.g., BullMQ or Cloud Run Jobs).
2. **Video Asset Ingestion**: Video files uploaded as workspace assets are supported and copied into the render directory, but very large video backgrounds (>500MB) can extend render times.

---

## 21. Recommended Phase 9

1. **Background Job Queue & Worker Scaling**: Decouple FFmpeg transcoding into asynchronous background queue workers with parallel rendering of 720p and 480p profiles.
2. **Audio Waveform & Music Track Selector**: Provide a visual audio waveform player for uploaded background music tracks in the Asset Library.
3. **Smart Video Trimming for Asset Videos**: Allow users to trim and select in/out points for uploaded video assets before passing them to the AI generator.
4. **Cloudflare Stream / AWS MediaConvert Direct Offload**: Direct integration with managed transcoding services for enterprise-scale transcoding pipelines.
