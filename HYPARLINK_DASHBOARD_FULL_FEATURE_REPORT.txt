--------------------------------------------------------------------------------
1. EXECUTIVE SUMMARY & PRODUCT MISSION
--------------------------------------------------------------------------------
Hyparlink Dashboard is a state-of-the-art web application and video creation platform
designed to democratize cinematic motion graphics and generative video production.
Built upon a modern full-stack monorepo (Turborepo + Bun), the platform converges
natural-language AI code generation, strict StaticGuard validation, headless Chrome
GPU timeline rendering, and the official HyperFrames visual Studio Editor into a
unified, cloud-ready web interface.

The web application allows individuals and creative teams to produce production-grade
videos from pure text descriptions, refine them in an embedded visual canvas, manage
brand assets, transcode them into multiple streamable formats, and collaborate across
isolated multi-tenant workspaces.


--------------------------------------------------------------------------------
2. SYSTEM ARCHITECTURE & ENGINE FOUNDATION
--------------------------------------------------------------------------------
The application is structured into four tightly decoupled, highly resilient tiers:

  [ Next.js 14 Frontend (:3000) ]
        |
        |-- Real-time reactive queries & mutations (WebSocket)
        v
  [ Self-Hosted Convex DB & Auth Engine (:3210 / :3211) ]
        |
        |-- Signed Webhook Dispatch & Job Queue Ingress
        v
  [ Backend Echo & Media Processor (:4000) ]
        |
        |-- AI Code Synthesis & StaticGuard Validation
        |-- Headless Chrome ANGLE Metal GPU Rendering
        |-- Apple Silicon Native FFmpeg Transcoder (1080p, 720p, 480p, WebP)
        |-- Unified Storage Layer (Local Disk / AWS S3 / Cloudflare R2)
        v
  [ Official HyperFrames Studio Daemon (Dynamic Port Pool :3055..:3075) ]
        |-- Deep-linked Visual Timeline Canvas embedded via Secure Sandbox <iframe>

  color palettes, and GSAP timing curves.

  provider, model latency, and runtime availability.

4. UNDER-THE-HOOD TECHNICAL ADVANCEMENTS
--------------------------------------------------------------------------------
1. StaticGuard Automated Self-Healing Loop:
   Before rendering, `npx hyperframes check --json` runs against the generated code.
   If CSS, layout, or timeline syntax errors occur, the compiler triggers a multi-attempt
   correction loop that parses compiler diagnostics and rewrites the code automatically.

2. Apple Silicon Headless Chrome GPU Acceleration:
   Video frames are rendered via Headless Chrome with ANGLE Metal GPU acceleration,
   achieving up to 4x faster export speeds than traditional CPU software canvas renderers.

3. Native Apple Silicon FFmpeg Transcoding:
   Directly executes the high-efficiency ARM64 FFmpeg binary bundled in HyperFrames to
   produce pristine 1080p, 720p, 480p MP4 files and WebP poster thumbnails in seconds.

4. Pluggable Cloud Storage Abstraction:
   Unified `IStorageProvider` interface supporting local byte-range streaming for dev,
   and AWS S3 / Cloudflare R2 object storage with ETag verification for production.
