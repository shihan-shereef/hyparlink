2. MORNING SESSION: DASHBOARD UI & WORKSPACE ASSET CONTROLS
--------------------------------------------------------------------------------

A. MULTI-SELECT "GET INSPIRED" IDEAS
   - Problem: The inspiration tags were single-select, preventing users from
     combining concepts like "Cinematic Trailer" + "Product Showcase".
   - Solution: Updated state management in `create-video/page.tsx` to support
     a set/array of selected inspiration items. Clicking a tag toggles it on/off;
     selected items are concatenated into the prompt or creative brief context.

B. MULTI-IMAGE ASSET UPLOAD & PREVIEW GRID
   - Problem: Users had to upload reference images one by one, with no thumbnail
     preview visible in the upload zone.
   - Solution: Added `multiple` attribute to the file input and updated the file
     handler to batch-process all selected images simultaneously. Built an
     instant thumbnail preview strip displaying image name, size, and dimensions.

C. WORKSPACE ASSET DELETION FIX
   - Problem: Deleting assets from the workspace assets library failed or left
     stale references.
   - Solution: Fixed the Convex mutation handler in `packages/backend/convex/assets.ts`
     and project asset synchronizer to reliably delete files and cascade updates
     to the UI without requiring page reloads.

D. DURATION (AUTHORITATIVE) CONTROLS & PROMPT OVERRIDE
   - Problem: If a user typed "Create a 10-second video..." but the dropdown was
     set to 15s, the system previously ignored the prompt and rendered 15s.
   - Solution:
     1. Added regular expression extractor `AIGenerator.extractDurationFromPrompt()`
        to detect durations like "10-second", "12s", "30 seconds", etc.
     2. When detected in the prompt, this duration overrides the UI dropdown.
     3. Added a "Custom" duration option in the UI allowing exact integer input
        from 3 to 120 seconds.
     4. Propagated the duration through Convex jobs, backend-echo, AI planning,
        and HyperFrames `data-duration` attributes.

3. AFTERNOON SESSION: HYPERFRAMES PROMPTING GUIDE INTEGRATION
--------------------------------------------------------------------------------
Implemented all 7 levels and the appendix from the official HeyGen HyperFrames
Prompting Guide (https://hyperframes.heygen.com/prompting/overview):

LEVEL 1 — YOUR FIRST VIDEO (VIDEO TYPE CATEGORIZATION)
  The AI identifies the true genre of the video rather than forcing every
  request into a corporate presentation deck:
  - `cinematic_animation`: Atmospheric lighting, rain, silhouette reveals, slow pans.
  - `nature_growth`: Botanical SVG rigs with roots, seed pulse, trunk, branches, leaves.
  - `network_architecture_explainer`: Client and server nodes with animated HTTP
    request and response packets.
  - `data_visualization`: Dynamic quarterly bar charts using supplied user numbers.
  - `abstract_motion_graphics`: Pure white geometric shapes on high-contrast #000000.
  - `product_ad`: Prominent hero asset display with surrounding animated badges.

LEVEL 2 — CONTROL (THE 6 PROMPT COMPONENTS)
  Structured creative planner (`creative-brief.ts`) extracts:
  1. Route: Creative category and intended visual path.
  2. Spec: Authoritative duration, dimensions (1920x1080), FPS (30), palette, fonts.
  3. Beats: Sequential scene breakdown with clear objectives and boundary math.
  4. Copy: Context-relevant headlines, subtitles, and badges tailored to the topic.
  5. Technique: SVG path drawing, GSAP transforms, bar charts, or media tags.
  6. Negatives: Explicit exclusion of corporate templates, placeholder text, and
     unrequested audio.

LEVEL 3 — LIFE (DETERMINISTIC MOTION PRINCIPLES)
  - Replaced layout properties (`left`, `right`) with GPU transforms (`x`, `y`,
    `scale`, `opacity`) complying with HyperFrames linter rules.
  - Replaced ungrounded client-side variables with Node-evaluated numeric expressions.
  - Implemented staggered reveals (`stagger: 0.06`, `ease: "back.out(1.7)"`) for
    natural organic motion.
  - Frame-accurate deterministic timelines suitable for seek-by-frame rendering.

LEVEL 4 — SUBSTANCE (BESPOKE VISUAL RIGS & ATMOSPHERES)
  - Built custom SVG generators for botanical growth, client-server network
    diagrams, and geometric shape systems.
  - Replaced generic `.bg-grid` with theme-tailored atmospheres:
    `nature-organic`, `pure-black`, `minimal-dark`, `cyber-hud`, `image-backdrop`.
  - Purged all hardcoded references to "OllaSoftware", "$1.4M / $5.8M",
    "1,000,000+ developers", and "ollasoftware-building.jpg".

LEVEL 5 — VOICE AND SOUND
  - Added structured `AudioPlan` schema (`isSilent`, `music`, `voiceover`, `soundEffects`).
  - Detected silent requests ("silent", "no audio"), setting `isSilent: true`.
  - Upgraded FFprobe inspector to check `hasAudio`, `audioCodec`, and `audioChannels`.

LEVEL 6 — SCALE (ASSETS, DURATION, AND BRANDING)
  - User assets (e.g. `hero-product.png`) are copied into the project `assets/`
    directory and directly embedded via `<img src="assets/hero-product.png">`.
  - User assets are never replaced with generic stock images.
  - Duration propagates authoritatively from prompt to final render.

LEVEL 7 — CAPSTONE & APPENDIX (ORCHESTRATION & AUTO-REPAIR)
  - Complete 8-stage pipeline: User Prompt -> LLM Understanding -> Creative Brief ->
    Scene Plan -> Dynamic Composition -> Validation -> Rendering -> Final Video.
  - Auto-Repair Loop: Catches HyperFrames linter codes (`gsap_non_transform_motion`,
    `missing_local_asset`, `invalid_data_duration`), re-prompts the AI model,
    and re-validates up to 3 times before rendering.
