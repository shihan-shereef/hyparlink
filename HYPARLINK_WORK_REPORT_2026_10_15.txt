2. ROOT CAUSE DIAGNOSTICS & SYSTEM INVESTIGATIONS
================================================================================

A. HeyGen Avatar API & Account Constraint Resolution:
   - Symptom: Dashboard users encountered "The string did not match the expected
     pattern" during avatar generation and noticed that random avatars and voices
     were selected instead of their own account's custom avatar.
   - Root Cause: Standard/Personal HeyGen accounts do not provide an API key creation
     portal (restricted to enterprise tiers), leading to authentication failures or
     unintended mock avatar fallbacks.
   - Solution: Designed and deployed a zero-API-key local avatar integration pipeline.
     Users can directly import their pre-generated HeyGen MP4 avatar clips (with green
     screen or alpha transparency) into the workspace. The backend automatically
     extracts the audio stream via FFmpeg, calculates speech duration, and binds the
     video element to HyperFrames timeline tracks with frame-accurate synchronization.

B. Disparity Analysis: Why Antigravity Videos Looked Superior:
   - Multi-Plane Depth: Previous dashboard compositions rendered text on a flat,
     single-color background. Antigravity compositions maintain three independent
     visual planes:
       * Background: Ambient technical dot grids (`radial-gradient`), dual drifting
         Gaussian blur orbs (`filter: blur(95px)`), and vignette shading.
       * Midground: Glassmorphic HUD telemetry cards (`backdrop-filter: blur(28px)`,
         `1px solid rgba(255,255,255,0.12)`, glowing accent borders, pulsing live status dots).
       * Foreground: High-contrast kinetic typography with background-clip gradients.
   - Camera Physics: Previous dashboard scenes were 100% static, giving a frozen
     appearance whenever speech paused. Antigravity enforces continuous slow camera
     push-ins (`tl.to("#root", { scale: 1.035, ease: "none" })`) across every scene.
   - Easing Curves: Previous dashboard templates used linear or quadratic eases
     (`power1.inOut`) causing stiff, simultaneous card appearances. Antigravity uses
     steep exponential eases (`power4.out`, `expo.out`) staggered by 0.08 seconds.
   - Verification Blindness: The dashboard previously rendered "blindly"—if a video
     had missing tags or corrupted frames, it was presented as "complete". Antigravity
     inspects frames post-render and self-heals errors autonomously.

B. AUTOMATED PRE-RENDER LINTER HEALER (5 STRICT HYPERFRAMES RULES)
File Modified: `ai-composition-generator/src/hyperframes/design-validator.ts`
--------------------------------------------------------------------------------
HyperFrames 0.8.139 enforces strict compile-time rules that cause hard render crashes
if violated. Added automated regex pattern matchers and surgical code healers:

1. `media_src_kind_mismatch`:
   - HyperFrames rejects `<img src="...mp4">` or `<video src="...png">`.
   - Healer: Detects `<img>` tags pointing to video files and converts them into
     `<video src="..." data-start="0" autoplay loop muted playsinline>` elements.
2. `media_missing_data_start`:
   - HyperFrames rejects any `<video>` element missing a `data-start` attribute.
   - Healer: Detects untimed video elements and auto-injects `data-start="0"`.
3. `duplicate_media_discovery_risk`:
   - HyperFrames errors when duplicate identical media clips exist within the same scene.
   - Healer: Strips duplicate video tags, keeping the primary instance clean.
4. `non_deterministic_code`:
   - HyperFrames prohibits `Math.random()` or non-deterministic variables in render timelines.
   - Healer: Replaces random tween values with fixed, deterministic seed offsets.
5. `gsap_timeline_set_initial_hide`:
   - Standalone `tl.set(...)` statements can cause timing desynchronization in HyperFrames.
   - Healer: Auto-converts standalone `tl.set()` calls into `gsap.set()` while safeguarding
     properly chained `.to()` tweens.

C. POST-RENDER AGENTIC QUALITY GATE & VISUAL STREAM AUDIT
File Modified: `ai-composition-generator/src/pipeline/generate-video.ts`
--------------------------------------------------------------------------------
Implemented a closed-loop quality gate that mimics Antigravity's inspect-and-correct
loop:

1. Post-Render File Validation:
   - Checks that the rendered MP4 file exists and exceeds 50 KB (detecting empty/truncated renders).
2. FFprobe Stream Audit:
   - Probes video stream metrics: Verifies 1920x1080 resolution, 30.00 fps progressive scan,
     H.264 High Profile encoding, and stereo AAC audio track presence.
3. Visual Keyframe Extraction & Frame Inspection:
   - Executes FFmpeg keyframe extraction at timestamps 1.0s, 3.0s, and 5.0s (`frame_01.jpg`, etc.).
   - Runs `FrameQualityAnalyzer.analyze()` to inspect frames for solid black output,
     corrupted pixels, or canvas initialization stalls.
4. Autonomous Repair Loop:
   - If any validation test fails, the pipeline does NOT present the flawed video.
   - Instead, it triggers `DesignValidator.inspectAndRepair(projectDir)`, corrects the
     underlying HTML/CSS/GSAP code, and triggers an automated re-render.
   - The video is only presented to the user once it passes all verification checks.
