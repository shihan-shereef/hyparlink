--------------------------------------------------------------------------------
MILESTONE 1: TIMELINE LANE OVERLAP & COLLISION FIX
--------------------------------------------------------------------------------
Problem:
  The Multitrack Timeline displayed overlapping lanes where Scene clips, Visual
  elements, Audio tracks, and Keyframes collapsed into one another. Users were
  unable to distinguish or click individual track elements.

Root Cause:
  The CSS classes used in the timeline tracks included non-existent Tailwind
  classes such as `h-13`. The browser defaulted to variable intrinsic heights,
  causing negative margin bleed and track stacking collisions.

Resolution:
  - Replaced arbitrary class names with explicit, rigid height definitions:
      * Track 1 (Scene Sequence): fixed `h-[52px]`
      * Track 2 (Visual Elements): fixed `h-[52px]`
      * Track 3 (Audio & Voiceover): fixed `h-[52px]`
      * Track 4 (Animation Keyframes): fixed `h-[40px]`
      * Timeline Container: fixed `h-[275px]` with strict overflow containment.
  - Verified 0px overlap between all lanes across the full 40-second composition.


--------------------------------------------------------------------------------
MILESTONE 2: ELEMENT SELECTION BOX POSITIONING FIX
--------------------------------------------------------------------------------
Problem:
  When tapping on layers in the Composition Hierarchy panel (e.g. scene-background,
  scene-content, eyebrow, headline, description), the selection box stayed stuck
  at a static arbitrary location on the canvas instead of wrapping the real element.

Root Cause:
  `scanLayers()` assigned synthetic dummy rect values ({ top: 120, left: 160 })
  rather than querying the actual rendered DOM geometry inside the canvas iframe.

Resolution:
  - Rewrote `scanLayers()` and the `HYPERLINK_SELECT_LAYER` postMessage handler in
    `interactive-canvas.tsx`.
  - Added dynamic `getBoundingClientRect()` calculations relative to the iframe's
    root canvas wrapper:
      * Exact pixel left, top, width, and height.
      * Live zoom scaling multiplication to ensure the overlay outline scales
        proportionally with user zoom.
  - Clicking any element in the canvas or layer hierarchy now positions the purple
    transform box precisely around the active element.


--------------------------------------------------------------------------------
MILESTONE 3: TIMELINE CUT (SPLIT) & MERGE (JOIN) IMPLEMENTATION
--------------------------------------------------------------------------------
Problem:
  Users were unable to split clips at the playhead or join adjacent clips back
  together, rendering the native timeline purely decorative.

Resolution:
  - Implemented `executeSplit(targetClipId?)`:
      * Identifies the target clip under the playhead across Scenes, Visuals, or Audio.
      * Calculates exact split timestamps based on `currentTime`.
      * Splits the clip into Part A (`start` to `currentTime`) and Part B (`currentTime`
        to `end`).
      * Injects unique stable IDs (`clip-split-N`) and persists timing to `index.html`.
  - Implemented `executeJoin()`:
      * Detects multiple selected clips or automatically selects the adjacent clip.
      * Validates track type compatibility and temporal continuity.
      * Merges both segments into a unified clip with combined duration.
      * Removes the split artifact cleanly.
  - Added Keyboard Shortcut `[J]` for Join and `[B]` for Split.
  - Added Merge icon in the timeline toolbar and context menu.
