# HyperFrames Composition Specification & Authoring Standard
**Report #5** — Project Structure, Syntax Contracts & AI Generation Rules

---

## 1. Required Project Folder Structure

A complete HyperFrames composition project follows this canonical directory layout:

```text
my-hyperframes-project/
├── package.json              # Defines scripts & pins CLI version
├── hyperframes.json          # Registry, asset, and block paths
├── meta.json                 # Project ID and name metadata
├── project.json              # Engine metadata & skill bindings
├── index.html                # Root composition timeline
├── compositions/             # Sub-compositions (modular scenes)
│   ├── 01_intro.html
│   ├── 02_discovery.html
│   └── ...
└── assets/                   # Static media (images, audio, video, fonts)
    ├── audio/
    └── images/
```

## 2. Required Files

1. **`index.html`**: The mandatory entry point declaring root canvas size, total duration, and assembling scenes.
2. **`package.json`**:
   ```json
   {

       "autoProxy": true
     }
   }
   ```

```html

      <!-- Modular Sub-Compositions -->
      <div id="scene-01" class="scene-host clip" data-composition-id="scene-01" data-composition-src="compositions/01_intro.html" data-start="0" data-duration="5" data-track-index="1"></div>

    <script>
      window.__timelines = window.__timelines || {};

```

## 4. CSS Structure & Layout Contract

* **Viewport Enclosure**: `body` and `#root` must declare explicit pixel dimensions or `width: 100%; height: 100%; overflow: hidden; position: relative;`.
* **The `.clip` Class**: Represents a visual scene container. Styled with `position: absolute; inset: 0; width: 100%; height: 100%;`.
* **Layering & Positioning**: Layers (background plates, vignettes, letterboxing, overlays) are stacked using `position: absolute; inset: 0;`. Content within overlays uses Flexbox or CSS Grid with `padding` and `max-width`.
* **Strict Rule**: **Never** apply an initial CSS `transform: translate(...)` on an element that GSAP subsequently animates with `x`, `y`, or `scale`. This creates a style battle that fails the compiler check (`gsap_css_transform_conflict`). Use `gsap.fromTo()` or Flexbox/Grid centering instead.

---

## 5. JavaScript / GSAP Animation Structure

* **Strictly Paused**: `const tl = gsap.timeline({ paused: true });`. The renderer seeks the timeline explicitly frame-by-frame; calling `tl.play()` is forbidden.
* **Deterministic Interpolation**: All animations must be built with standard GSAP methods (`.to()`, `.from()`, `.fromTo()`) using deterministic offsets or position parameters (`0`, `0.5`, `"+=0.2"`):
  ```javascript
  const tl = gsap.timeline({ paused: true });
  // Camera zoom across scene
  tl.to("#bg-image", { scale: 1.08, duration: 5.0, ease: "none" }, 0);
  // Title reveal
  tl.fromTo("#hero-title", { opacity: 0, y: 30 }, { opacity: 1, y: 0, duration: 1.0, ease: "power2.out" }, 0.5);
  // Exit fade
  tl.to("#hero-title", { opacity: 0, y: -20, duration: 0.6, ease: "power2.in" }, 4.4);
  ```
* **No Dynamic Clocks**: `Date.now()`, `performance.now()`, unseeded `Math.random()`, or `requestAnimationFrame` are strictly prohibited.

## 6. How HyperFrames Defines Video Duration

* Video duration is defined **statically at compile time** on the root element:
  ```html
  <div id="root" data-composition-id="main" data-duration="62" ...>
  ```
* **Compile-Time Rule**: The root `data-duration` is locked before inline scripts evaluate. Scripts cannot change the total render length via `setAttribute("data-duration")`.
* If omitted on the root, HyperFrames derives total duration from the latest clip's `data-start + data-duration` or the longest registered GSAP timeline.

---

## 7. How `data-start` and `data-duration` Are Used

* **`data-start`**: Timestamp in seconds when an element becomes active. Marking an element with `data-start` makes it a timed clip.
* **`data-duration`**: Length of time in seconds the element remains visible.
* **Half-Open Interval**: Visibility follows `[start, start + duration)`. At exactly `t = start + duration`, the element is automatically hidden.
* **Consecutive Scenes**: Scene B starts exactly when Scene A ends:
  * Scene A: `data-start="0" data-duration="5.5"`
  * Scene B: `data-start="5.5" data-duration="5.0"`

---

## 8. How `window.__timelines` Is Structured and Used

* HyperFrames exposes a global registry: `window.__timelines`.
* Each composition assigns its paused timeline keyed by its `data-composition-id`:
  ```javascript
  window.__timelines["scene-01"] = tl;
  tl.seek(0);
  ```
* **Auto-Nesting**: In modular sub-compositions, child timelines registered under their respective IDs are automatically discovered and scrubbed by the root player in sync with `data-start`.
* **Puppeteer Capture**: During rendering, headless Chrome calls `window.__timelines["main"].seek(t)` at each discrete frame time ($\Delta t = 1 / \text{FPS}$) and takes a screenshot or Paint snapshot.

## 9. How Scenes and Animations Are Organized

### A. Modular Sub-Compositions (Production Standard)
* `index.html` acts as the master timeline.
* Scenes are separated into `compositions/01_intro.html`, `compositions/02_feature.html`, etc.
* Each sub-composition has its own `<head>`, fonts, styles, DOM, and GSAP timeline.
* Mounted in `index.html` via:
  ```html
  <div class="scene-host clip" data-composition-id="scene-01" data-composition-src="compositions/01_intro.html" data-start="0" data-duration="5.5"></div>
  ```

### B. Monolithic Standalone
* All scenes live in one `index.html` as stacked `<div class="clip" data-start="..." data-duration="...">` elements.
* Best for short videos (<15 seconds) or simple motion graphics.

## 10. Referencing Assets (Media, Fonts, Audio)

1. **Images**: `<img src="assets/scene_01.jpg" class="cinematic-bg" alt="...">`.
2. **Audio**:
   ```html
   <audio id="master-soundtrack" src="assets/audio/music.mp3" data-start="0" data-duration="62" preload="auto"></audio>
   ```
   * *Critical*: Every `<audio>` element **must have an `id`**. Without an `id`, it fails the linter (`media_missing_id`) and the audio mixer drops it, rendering a silent video.
3. **Video**:
   ```html
   <video src="assets/footage.mp4" data-start="0" data-duration="6" data-has-audio="true" preload="auto"></video>
   ```
   * *Critical*: Never add `crossorigin` to `<video>` or `<audio>`.
   * *Critical*: Never nest a `<video data-start>` inside an ancestor that also has `data-start`.
4. **Fonts**: Standard `<link rel="stylesheet">` to Google Fonts or local `@font-face` in `<style>`.

## 11. Resolution, FPS, and Aspect Ratio Configuration

1. **Resolution & Aspect Ratio**: Configured directly on the root `<div>`:
   * **16:9 Landscape (1080p)**: `data-width="1920" data-height="1080"`
   * **9:16 Portrait (Shorts / Reels)**: `data-width="1080" data-height="1920"`
   * **1:1 Square (Instagram / Ads)**: `data-width="1080" data-height="1080"`
2. **Frame Rate (FPS)**:
   * Declared on root: `data-fps="30"` (or `data-fps="60"`).
   * Overridden via CLI render flag: `--fps=30` or `--fps=60`.

## 15. What Causes AI-Generated Compositions to Fail (`npx hyperframes check`)

| Mistake | Linter Error Code | Root Cause & Fix |
|---|---|---|
| CSS `transform` + GSAP Tween | `gsap_css_transform_conflict` | Element has `transform: translateY(20px)` in CSS, and GSAP animates `y`. **Fix**: Set initial state in `gsap.fromTo()`. |
| `<audio>` missing `id` | `media_missing_id` | Audio tag has no `id`. Audio mixer drops it, rendering a silent video. **Fix**: Add `id="soundtrack"`. |
| `crossorigin` on media | `media_crossorigin_breaks_preview` | Adding `crossorigin` to `<video>` or `<audio>`. **Fix**: Remove attribute entirely. |
| Nested `<video data-start>` | `video_nested_in_timed_element` | `<video data-start>` inside a wrapper that also has `data-start`. **Fix**: Put timing on the wrapper or the video, never both. |
| Animating `.clip` visibility | `gsap_animates_clip_element` | Tweening `visibility`, `display`, or `autoAlpha` on `.clip`. **Fix**: Animate child element or use `opacity`. |
| Mismatched timeline ID | Stalled render at t=0 | `window.__timelines["wrong-id"]` does not match `data-composition-id="main"`. |
| Calling `tl.play()` | Non-deterministic frame desync | Engine seeks frame-by-frame; calling `.play()` causes timing drifts. **Fix**: Keep timeline paused. |
| Early timeline registration | `gsap_timeline_registered_before_async_build` | Assigning `window.__timelines["id"] = tl` before async font/asset loading completes. **Fix**: Assign key at the end of callback. |
